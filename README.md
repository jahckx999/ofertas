# Garimpo Diário

Vitrine de ofertas (afiliado Mercado Livre) publicada no GitHub Pages, com captura de leads no Supabase e robô diário no Claude.

- `index.html` — vitrine, funil e formulário de alertas
- `privacidade.html` — política de privacidade (LGPD)
- `tools/gerar_imagem.py` — gera as artes do post do dia (feed 1080x1350, story 1080x1920)
- `posts/` — artes publicadas pelo robô (usadas pelo Instagram/Facebook)

Nenhuma chave secreta fica aqui: a chave do Supabase no site é a publicável, e o banco só aceita inserir leads/cliques (leitura bloqueada).
